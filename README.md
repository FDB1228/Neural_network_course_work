# Нейронная сеть для распознавания рукописных цифр (MNIST) на C++

Курсовая работа (МГТУ им. Н. Э. Баумана, факультет фундаментальных наук, 2025 г.). Многослойный персептрон 784–256–10, написанный с нуля на C++ без сторонних библиотек: собственный класс матриц, прямое и обратное распространение ошибки, обучение и тестирование на датасете MNIST.

**Коротко:**

- сеть с одним скрытым слоем (256 нейронов), реализованная только средствами стандартной библиотеки C++;
- три функции активации на выбор: сигмоида и две модифицированные функции (Leaky ReLU и th(x)), адаптированные под входные данные в диапазоне [0, 1);
- лучший результат на тестовой выборке из 10 000 изображений: **92,58 %** (модифицированный Leaky ReLU), по сравнению с 74,75 % у сигмоиды и 85,32 % у модифицированного th(x);
- в репозитории есть расчётно-пояснительная записка и презентация: [`docs/report.pdf`](docs/report.pdf), [`docs/presentation.pdf`](docs/presentation.pdf).

## Задача и данные

Классификация изображений рукописных цифр 28×28 пикселей на 10 классов (0–9).

- **Данные:** MNIST в формате CSV: 60 000 обучающих и 10 000 тестовых примеров. В строке 785 значений: метка класса и 784 значения яркости пикселей от 0 до 255.
- **Предобработка:** яркость каждого пикселя делится на 256, поэтому на вход сети подаются значения из диапазона [0, 1).
- **Формат файла:** программа ожидает заголовок в первой строке, первая ячейка которого равна `label`. Файлы без заголовка она не примет.

## Архитектура сети

| Слой      | Нейронов | Примечание                                         |
| --------- | -------- | -------------------------------------------------- |
| Входной   | 784      | по одному нейрону на пиксель                        |
| Скрытый   | 256      | полносвязный, со смещениями (bias)                  |
| Выходной  | 10       | по одному нейрону на цифру; ответ — номер нейрона с максимальным значением |

Конфигурация читается из файла `Config.txt`: первая строка `NetWork <число слоёв>`, вторая строка содержит количество нейронов в каждом слое. Например, для этой сети:

```
NetWork 3
784 256 10
```

Начальные веса и смещения задаются малыми случайными положительными значениями.

### Функции активации

Функция выбирается при запуске программы. Так как входные значения лежат в [0, 1), стандартные Leaky ReLU и th(x) были доопределены:

| Функция                          | Определение                                                       |
| -------------------------------- | ----------------------------------------------------------------- |
| Сигмоида                         | f(x) = 1 / (1 + e^(−x))                                           |
| Модифицированный Leaky ReLU      | 0,01·x при x < 0; x при 0 ≤ x ≤ 1; 1 + 0,01·(x − 1) при x > 1     |
| Модифицированный th(x)           | th(x) при x ≥ 0; 0,01·th(x) при x < 0                             |

## Обучение

- Метод: обратное распространение ошибки, стохастический градиентный спуск (веса обновляются сразу после каждого примера).
- Веса меняются **только на тех примерах, которые сеть классифицировала неверно**.
- Скорость обучения убывает по эпохам: `0,15 · exp(−эпоха / 20)`.
- Остановка: после 20 эпох или при достижении 100 % точности на обучающей выборке.
- Для каждой эпохи программа печатает точность (считается по ходу прохода по обучающей выборке), максимальную точность и время эпохи. После обучения выводится общее время.

## Результаты

Точность на тестовой выборке MNIST (10 000 изображений), 20 эпох обучения (значения из отчёта):

| Функция активации               | Точность   |
| ------------------------------- | ---------- |
| Сигмоида                        | 74,75 %    |
| Модифицированный th(x)          | 85,32 %    |
| **Модифицированный Leaky ReLU** | **92,58 %** |

Начальные веса задаются генератором случайных чисел, инициализируемым текущим временем, поэтому при повторном запуске значения могут отличаться. Подробный разбор функций активации, формулы обратного распространения и графики приведены в [отчёте](docs/report.pdf).

## Как собрать и запустить

Проект создан в Visual Studio 2022 и рассчитан на Windows (в коде используется `system("pause")`).

1. Склонируйте репозиторий:
   ```
   git clone https://github.com/FDB1228/neural_network_course_work.git
   ```
2. Положите `mnist_train.csv` и `mnist_test.csv` в папку `src/`, рядом с `Neural network.vcxproj` и `Config.txt`. Программа ищет эти файлы в рабочей папке проекта.
3. Откройте `src/Neural network.sln` в Visual Studio.
4. Выберите конфигурацию **Release | x64** (в Debug обучение заметно медленнее) и запустите без отладки: `Ctrl+F5`.
5. Отвечайте на вопросы в консоли:
   - `Choose activate function` — функция активации: `1` сигмоида, `2` Leaky ReLU, `3` th(x). Лучший результат даёт `2`;
   - `STUDY? (1/0)` — `1`: обучить сеть;
   - `Test? (1/0)` — `1`: проверить точность на `mnist_test.csv`; программа напечатает `RA` и долю верных ответов в процентах;
   - `Repeat? (1/0)` — повторить цикл.

После обучения веса и смещения сохраняются в файл `Weights.txt` (около 3 МБ, в репозиторий он не входит). В следующий раз можно не обучать сеть заново: на вопрос `STUDY? (1/0)` ответьте `0`, и веса загрузятся из файла. Функцию активации при этом нужно выбрать ту же, что и при обучении.

Другие компиляторы, кроме MSVC, потребуют добавить `#include <cmath>` в `ActivateFunction.cpp`.

## Известные ограничения

- **Обратное распространение реализовано упрощённо.** В `ActivateFunction` есть функция `useDer(double*, int)`, считающая производную по значению на выходе нейрона, но при обучении вызывается перегрузка `useDer(double)`. Для сигмоиды она возвращает значение самой сигмоиды, а в ветке ReLU нет `break`, и выполнение проваливается в ветку th(x). Поэтому формулы из отчёта соответствуют коду лишь приближённо. Сравнение функций активации проведено на этой реализации, и разницу в точности (74,75 % / 85,32 % / 92,58 %) нельзя целиком объяснять свойствами самих функций.
- **Точность ниже достижимой.** Для полносвязных сетей с одним скрытым слоем на MNIST обычно получают около 97–98 %, поэтому у проекта есть запас для улучшения.
- **Учебный код.** Память выделяется вручную без деструкторов, нет проверок входных данных, результаты не детерминированы из-за случайной инициализации.

## Что можно улучшить

- Исправить производные в обратном распространении, заново обучить сеть и обновить таблицу результатов.
- Перейти на мини-батчи, функцию softmax на выходе и перекрёстную энтропию.
- Использовать инициализацию весов Хе или Ксавье.
- Освободить память в деструкторах (или заменить массивы на `std::vector`).
- Добавить `CMakeLists.txt` для сборки не только в Visual Studio.
- Сравнить результат с эталоном (например, `MLPClassifier` из scikit-learn) на тех же данных.
